# 传统美股券商路线总览

最后人工核验：`2026-08-26`

传统券商仍是理解“真正证券账户”的基准。它通常提供更标准的交易确认、月结单、现金股息、公司行动和转仓能力，但开户审核、地址/税务材料和银行电汇比交易所路径更复杂。

## 当前可从官方页面核验的三家

| 券商 | 中国居民相关官方信息 | 开户/交易特点 | 入金主线 |
| --- | --- | --- | --- |
| Interactive Brokers（IBKR） | 可接受国家列表包含中国；有中国居民材料专页 | 市场多、工具专业、费用结构较复杂 | 同名银行电汇、支持的银行转账/转仓 |
| Charles Schwab International | 国际申请流程对符合条件地区开放；官方有中国居民证件提示 | 美股/ETF 在线交易 0 佣金，国际账户资料要求完整 | 电汇、支票、券商转仓等，以账户指示为准 |
| Firstrade | 国际账户支持地区明确包含中国 | 中文界面、0 佣金、开户流程相对简单 | 国际电汇；本人有美国银行时可 ACH |

“官网列出中国”表示可以提交申请，不代表每位申请人必然获批，也不代表任何一种境内资金路径必然可用。券商会根据常住地、证件、税务身份、职业、资金来源和当时政策审核。

## 通用开户流程

1. 只从券商官方域名开始申请。
2. 选择 `Individual/个人` 与 `Cash/现金账户`；新手不需要先开保证金。
3. 用护照/身份证件上的法定姓名填写，地址与证明材料一致。
4. 如实填写职业、资产、收入、资金来源、交易经验和税务居民信息。
5. 上传清晰的身份证件与地址证明。
6. 完成 W-8BEN 或券商的替代表格。
7. 等待审核与补件通知；只通过登录后的消息中心或官方联系方式沟通。
8. 获批后从账户内生成最新电汇指示，先小额测试。
9. 入账后核对基础货币、换汇成本和市场数据权限。
10. 用小额限价单跑通买入、持仓、卖出和出金。

## 怎么选

- 需要全球市场、专业交易工具、API、期权或未来扩展：先研究 IBKR。
- 主要买美国股票/ETF、偏好大型综合券商和国际客户服务：研究 Schwab International。
- 重视中文体验、简单的美股国际账户和 0 佣金：研究 Firstrade。
- 已经有 USDT/USDC，主要诉求是小额和快速进入：再与 [四家交易所路径](../README.md#四个快捷入口领取-20-手续费优惠) 对比。

## 券商路线仍要核对的五件事

1. **服务实体**：你的账户实际开在哪个法人实体下？
2. **保护范围**：是否为 SIPC 成员账户，哪些资产属于合格证券/现金？SIPC 不保护市场下跌。
3. **电汇总成本**：汇出行、中间行、收款行和换汇分别收费多少？
4. **税务文件**：W-8BEN 状态、股息预扣和年度文件在哪里查看？
5. **退出能力**：能否 ACATS/国际转仓、出金到哪些同名账户、费用与时间？
