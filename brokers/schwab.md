# Charles Schwab International 开户与首单

最后人工核验：`2026-08-26`

Schwab International 为符合条件国家/地区的非美国居民提供国际账户在线申请。官方当前开户入口允许先选择常住国家/地区，并对中国居民提供身份证件提示（[S-SCH-01](../SOURCES.md#s-sch-01)、[S-SCH-02](../SOURCES.md#s-sch-02)）。

## 适合谁

- 主要投资美股和 ETF；
- 偏好大型美国综合券商、国际客户服务和较标准的证券账户；
- 能准备护照/身份证件、地址证明和国际电汇；
- 不把复杂 API 或全球小市场覆盖作为第一需求。

## 开户前准备

官方当前页面列出的常见材料包括：

- 护照或可接受的政府身份证件；中国居民页面有居民身份证提示；
- 最近的水电气/有线电视等地址证明，或页面接受的其他居住证明；
- 税号/税务身份信息；
- 雇主名称和地址（如适用）；
- W-8BEN 替代表格所需信息。

## 开户步骤

1. 从 Schwab International 官方开户页选择常住国家/地区。
2. 选择 `Individual International Account`。
3. 阅读并同意国际账户声明。
4. 用证件完全一致的法定姓名填写个人和联系方式。
5. 填写护照/政府 ID、当前实际居住地址、职业、资金来源和投资目的。
6. 上传清晰证件与地址证明。
7. 完成 W-8BEN/税务声明和电子签署。
8. 提交审核。官方流程说明一般可能需数天到两周，补件会延长时间。
9. 收到激活通知后再入金。

## 一个容易被旧教程写错的点

Schwab 的 2021 年旧版中文 PDF 曾写 25,000 美元最低开户资金，但当前国际官网写明个人/联名账户**没有最低开户存款**。本仓库以当前产品页优先，并保留旧文件冲突作为“不要抄旧教程”的例子（[S-SCH-03](../SOURCES.md#s-sch-03)）。下单前仍应以你申请实体的最新定价与开户确认信为准。

## 入金

当前官网列出银行电汇、邮寄支票和从其他券商转仓等方式：

1. 账户激活后登录，打开 Funding/Move Money 的最新指示；
2. 按币种获取当次收款银行与附言；
3. 从本人同名账户发起小额测试；
4. 核对中间行扣费、到账金额和可交易余额；
5. 不在账户激活前提前汇款。

## 第一笔订单

1. 搜索公司名和股票代码，核对交易所与币种。
2. 选择 `Trade → Stocks & ETFs`。
3. 输入 `Buy`、数量、订单类型和有效期。
4. 第一次优先小额限价单，并确认是否参与延长时段。
5. 预览佣金、费用和估算金额后提交。
6. 在 Order Status、Positions 和 Statements 核对。

Schwab 当前国际官网称在线美国上市股票交易佣金为 0 美元，但 OTC、期权合约、经纪人协助、ADR、交易所和其他费用仍可能适用。
