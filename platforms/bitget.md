## 二、Bitget Stock+：真实美股证券服务

### 产品本质

Bitget 官方称 Stock+ 与美国持牌券商 RQD Clearing、Atomic Vaults Securities 合作，订单路由至 Nasdaq、NYSE 和受监管做市商；用户可买卖和持有真实美股，并获得现金/股票股息及投票权。证券资产由合作清算券商托管（[S-BIT-01](../SOURCES.md#s-bit-01)）。

官方还称可交易 10,000 多只美股和 ETF，支持最低 0.0001 股和延长交易时段。产品只对符合条件的账户开放，最终权益行使、资产保护和转仓以证券子账户协议为准。

### 开立证券子账户

1. 打开 Bitget App，点首页右上角 `Stock+`。
2. 第一次进入选择 `Open Now`。
3. 完成高级身份认证；系统通常复用主账户信息，但仍需填写证券账户资料和同意协议。
4. 确认证券服务实体、常住地准入、税务声明、客户资产托管和费用。
5. 等待 Stock+ 子账户开通。

### 入金

1. 主账户没有 USDC：先通过账户实际开放的渠道充值/兑换为 USDC。
2. 进入 `Assets → Transfer`。
3. 选择从主账户转到 `Stock+` 证券子账户，资产为 USDC。
4. 输入金额并确认。官方称内部 USDC 划转免费，证券子账户使用 USD 定价与结算。

### 买入与管理

1. 在 Stock+ 搜索股票代码或公司名，例如 `AAPL`、`NVDA`、`TSLA`。
2. 打开详情页，确认没有 `r` 前缀、没有 `PERP` 和杠杆控件。
3. 选择 `Buy`，输入股数/金额和价格。
4. 在预览页核对交易时段、订单类型、费用、预计股数和结算金额。
5. 成交后到 `Assets → Positions/Order history` 查看持仓和记录。
6. 卖出时选择 `Sell`；结算、可提现时间和公司行动以子账户页面为准。

## 三、rToken：Reality 股票代币

### 产品本质

rToken 是 Reality 发行的股票代币。Bitget 官方说明称底层由持牌券商托管的真实股票 1:1 支持，代币持有人获得相应经济敞口和股息处理，但不是通过传统券商账户直接持股；当前不提供投票权（[S-BIT-02](../SOURCES.md#s-bit-02)）。

### 买入步骤

1. 进入 `Markets/Trade → Stocks → Spot stocks`。
2. 搜索带 `r` 前缀的代码，例如 `rAAPL`、`rTSLA`、`rNVDA`。
3. 确认发行人是 Reality，交易对、网络和产品说明与官方一致。
4. 使用 USDT 选择限价或市价订单。
5. 输入数量并预览费用、价差和最小交易额。
6. 成交后在 Assets 查看 rToken；股息按产品规则自动记账。

### 核对点

- 1:1 储备和审计/证明在哪里发布；
- 代币能否提链、合约地址和支持网络；
- 普通用户能否赎回底层、最低额和费用；
- 股息税费、拆股和退市如何处理；
- 周末流动性与相对美股最后价格的偏离。

## 四、股票永续

### 产品本质

Bitget 股票永续是 USDT 本位衍生品，不持有股票。官方 2026 年指南列示 24/7 交易、最高 100x 杠杆、可开多开空，资金费率通常每 8 小时结算（[S-BIT-03](../SOURCES.md#s-bit-03)）。最高值会按合约和风险档位变化，且不适合作为默认设置。

### 操作路径

1. 进入 `Trade/Markets → Stocks` 或 `TradFi → Stock Perps`。
2. 搜索目标合约，确认名称含永续标识，结算资产为 USDT。
3. 打开合约详情，检查指数成分、标记价格、资金费率、最小数量和杠杆档位。
4. 划转小额 USDT 到合约账户。
5. 初次使用逐仓与低杠杆；明确开多或开空。
6. 输入数量，设置止盈止损，再提交限价/市价单。
7. 持仓时查看标记价格、强平价、保证金率和下一次资金费用。

100x 意味着非常小的反向波动就可能消耗保证金。收益截图通常忽略强平概率、资金费率、滑点和无法复现的入场点，不应拿来倒推仓位。

## 五、怎么选

- 要真实美股、证券子账户和较完整股东权益：优先核验 Stock+ 是否对本人开放。
- 要 USDT 现货、24/7 和代币化敞口：比较 rToken 的储备、价差、股息和退出路径。
- 要开空/杠杆：使用股票永续，但从低杠杆、逐仓和可承受归零的小额开始。

三种产品可能出现在同一个 Stocks 入口。最简单的识别方法：`AAPL` 是 Stock+ 候选，`rAAPL` 是代币，带 `PERP`/杠杆/强平价的是永续；最后仍以详情页条款为准。
